十幾個 repo 同時開，也不會亂Juggle a dozen repos without the chaos

GitDeck 用的就是你電腦裡的 git，看到的指令和終端機打的一模一樣；所有操作都在同一個視窗、同一排分頁裡完成。GitDeck drives the git already on your Mac — the same commands you would type in Terminal — and everything happens in one window and one row of tabs.

🗂️

Bookmarks + 分頁Bookmarks + tabs

點 bookmark 開成分頁，已經開過的直接切過去。下次打開 App 會恢復上次的分頁。Click a bookmark to open it as a tab, or jump to it if it’s already open. Your tabs come back next launch.

📁

群組與掃描Groups & folder scan

用群組整理 bookmarks、拖曳排序；掃描資料夾自動找出所有 repo，也能直接從 Finder 拖進來。Organize bookmarks into groups and drag to reorder. Scan a folder to find every repo, or drop folders in from Finder.

🌿

Commit graphCommit graph

分支線、merge 一目了然，branch、remote、tag、HEAD 直接標在 commit 上，可切換全部分支或目前分支。Branch lanes and merges at a glance, with branch, remote, tag and HEAD labels on each commit. Show all branches or just the current one.

✂️

逐 hunk stageStage by hunk

Staged／Unstaged 兩個列表，一個檔案裡也能只 stage、unstage 或 discard 其中一段。Separate staged and unstaged lists — stage, unstage or discard a single hunk inside a file.

🔀

Interactive rebaseInteractive rebase

pick、reword、squash、fixup、drop，拖曳調整順序，不用再編輯 todo 檔。Pick, reword, squash, fixup or drop, and drag to reorder — no todo file to edit.

⚔️

衝突處理Conflict handling

ours／theirs、Mark resolved、開外部 merge tool；merge 或 rebase 進行中，上方會出現 Continue／Skip／Abort。Take ours or theirs, mark resolved, or open your merge tool. A banner offers Continue, Skip or Abort mid-merge or rebase.

🔍

搜尋、Blame、File logSearch, blame, file log

依 message、作者、內容（-S）、路徑或 SHA 搜尋；單一檔案的歷史和逐行 blame。Search by message, author, content (-S), path or SHA. Per-file history and line-by-line blame.

🖥️

Console 看得到指令See every command

GitDeck 實際執行的每一行 git 指令和輸出都在 Console（⇧⌘K），想學 git 或除錯都很方便。Every git command GitDeck runs, and its output, appears in the Console (⇧⌘K) — great for learning or debugging.

FAQ

常見問題Questions

真的免費嗎？Is it really free?

是的，沒有試用期、沒有廣告，也不會收集任何資料。Yes. No trial, no ads, and no data collection.

需要另外裝 git 嗎？Do I need git installed?

需要。GitDeck 會依序找 Homebrew 的 git（/opt/homebrew、/usr/local），沒有就用系統的 /usr/bin/git；也可以在 Settings 指定路徑。Yes. GitDeck looks for Homebrew’s git first (/opt/homebrew, /usr/local) and falls back to /usr/bin/git. You can also set a path in Settings.

帳號密碼、SSH key 怎麼處理？How are passwords and SSH keys handled?

跟終端機一樣：HTTPS 走 macOS Keychain（osxkeychain），SSH 用你的 ~/.ssh 設定。需要輸入帳密或 passphrase 時會跳出原生對話框，GitDeck 本身不保存任何密碼。Just like Terminal: HTTPS uses the macOS Keychain (osxkeychain) and SSH uses your ~/.ssh config. When git needs a password or passphrase, a native dialog asks for it — GitDeck itself stores nothing.

跟 SourceTree 有什麼關係？Is this related to SourceTree?

沒有關係。GitDeck 是獨立開發的，只是版面參考了 Windows 版 SourceTree 的單一視窗設計。No. GitDeck is independent; its single-window layout is simply inspired by SourceTree for Windows.

支援哪些 Mac？Which Macs are supported?

macOS 13 Ventura 以上，Apple silicon 和 Intel 都可以。macOS 13 Ventura or later, on Apple silicon and Intel.

發現問題或有建議？Found a bug or have an idea?

歡迎到 GitHub Issues 告訴我。Please open an issue on GitHub.
