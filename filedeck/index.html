從 Windows 換到 Mac，不用重新學怎麼管檔案Switched from Windows? Keep how you manage files.

Finder 很好，但手指記得的是另一套。FileDeck 把檔案總管的習慣原封不動搬過來，又跟 macOS 的垃圾桶、快速查看、替身完全相容。Finder is fine — your fingers just learned a different set of moves. FileDeck brings those habits over while working with macOS Trash, Quick Look and aliases.

↵

Enter 就是打開Enter means open

進入檔案夾、開啟檔案、啟動 App 都是 Enter；Backspace 回上一頁，沒有上一頁就到上層。Enter opens folders, files and apps. Backspace goes back — or up a level when there’s nowhere back to go.

✂️

真正的剪下貼上Real cut & paste

⌘X 剪下、⌘V 貼上就是搬移；名稱衝突自動保留兩者，絕不覆蓋。大量複製有進度視窗。⌘X then ⌘V moves files. Name clashes keep both copies — nothing is ever overwritten. Big copies show progress.

🏷️

F2 改名F2 to rename

只選主檔名、不動副檔名，Enter 確定、Esc 取消，⌘Z 可還原。直接打字會跳到該名稱的檔案。Selects just the name, not the extension. Enter to confirm, Esc to cancel, ⌘Z to undo. Type to jump to a file.

🗂️

分頁與多視窗Tabs and windows

⌘T 開新分頁、⌘N 開新視窗，拖放在視窗、分頁和側邊欄之間都能用。⌘T for a new tab, ⌘N for a new window. Drag and drop works between windows, tabs and the sidebar.

🖼️

詳細資料 / 縮圖Details or thumbnails

⌘1 清單、⌘2 縮圖；圖片、PDF、影片用 Quick Look 產生實際縮圖，7 段大小，⌘＋捲動縮放。⌘1 for a list, ⌘2 for thumbnails with real Quick Look previews of images, PDFs and videos. 7 sizes, ⌘-scroll to zoom.

📄

右鍵新增檔案New file from the menu

空白處右鍵 › 新增：文字文件、Markdown、RTF、HTML、空白檔案，建立完直接改名。Right-click › New: text document, Markdown, RTF, HTML or an empty file — ready to rename.

建立捷徑Create shortcut

右鍵「建立捷徑」或「在桌面建立捷徑」，產生的是 macOS 替身，原檔搬走也找得到。Right-click › Create Shortcut, or put one on the Desktop. They’re real macOS aliases that follow the original.

FAQ

常見問題Questions

真的免費嗎？Is it really free?

是的，沒有試用期、沒有廣告，也不會收集任何資料。Yes — no trial, no ads, and no data collection.

會取代 Finder 嗎？Does it replace Finder?

不會，兩者可以同時使用。FileDeck 用的就是 macOS 自己的垃圾桶、替身、標籤和 Quick Look，在哪邊操作另一邊都看得到。No, they work side by side. FileDeck uses macOS’s own Trash, aliases and Quick Look, so changes show up in both.

丟到垃圾桶可以救回來嗎？Can I get files back from the Trash?

可以。⌘⌫ 是丟到 macOS 的垃圾桶，⌘Z 可以還原；只有 ⇧Delete 會直接刪除，而且會先確認。Yes. ⌘⌫ moves to the macOS Trash and ⌘Z undoes it. Only ⇧Delete deletes immediately — and it asks first.

為什麼一直問我要不要允許存取資料夾？Why does macOS keep asking for folder access?

這是 macOS 對桌面、文件、下載項目和外接磁碟的保護。每個位置允許一次就好；或在「系統設定 › 隱私權與安全性 › 完整磁碟取用權限」加入 FileDeck。That’s macOS protecting Desktop, Documents, Downloads and external drives. Allow each once, or add FileDeck under System Settings › Privacy & Security › Full Disk Access.

支援哪些 Mac？Which Macs are supported?

macOS 13 Ventura 以上，Apple silicon 和 Intel 都可以。macOS 13 Ventura or later, on Apple silicon and Intel.
