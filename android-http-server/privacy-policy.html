HTTP Server — Privacy PolicyHTTP Server 隱私權政策

Effective date: November 2, 2026 · App ID: com.bittyferrari.http_server 生效日期：2026 年 11 月 2 日 · App ID：com.bittyferrari.http_server
In short: HTTP Server does not collect, store on any remote server, sell or share your personal data. It has no accounts, no ads, no analytics and no tracking. Everything the app does happens on your device and your local network.

1. What the app does

HTTP Server turns your Android device into a web server on your local Wi-Fi network. Other devices on the same network can open the shown address in a browser to browse, download and (if you allow it) upload files in a folder you choose, and to play the built-in browser games with each other.

2. Information we collect

We (the developer) do not collect any information. The app contains no analytics, advertising, crash-reporting or tracking SDKs, and it does not send any data to the developer or to any third-party server.

3. Data stored on your device

The following is stored only in the app's private storage on your device and is never transmitted to us:

DataPurpose
Settings (port, language, theme, site name, read-only mode, selected network address)Remember your preferences
Access to the folder you picked (via the Android system folder picker)Serve that folder's files; the app cannot see other folders
Optional access passwordProtect the server from other people on your network

You can remove all of this at any time by clearing the app's data or uninstalling the app. You can also revoke folder access in Android settings.

4. Files and local network activity

  • Files are transferred directly between your device and the browsers that connect to it over your local network. They do not pass through any server of ours.
  • While the server is running, the app may show recent activity (for example, which device address visited, downloaded or uploaded a file) so you can see who is using your server. This is shown on your device only.
  • Names that players type in the browser games, and game state, are kept in memory only while the server is running and are only shared with other players in the same game room.
  • Anyone on the same network who knows the address can reach the server. We recommend enabling the password and read-only mode, and only running the server on networks you trust. Connections use plain HTTP on your local network and are not encrypted.

5. Permissions

PermissionWhy

The app does not request access to your contacts, location, camera, microphone, or all files on your device.

6. Third-party services

  • Google Fonts: the web page served to browsers may load a font from Google Fonts if that browser has internet access. Google may receive the browser's IP address as part of that request. See Google's Privacy Policy.
  • PayPal: the optional "donate" link opens PayPal in your browser. Anything you do there is governed by PayPal's Privacy Statement.
  • Google Play: if you install the app from Google Play, Google may collect information under its own policies.

7. Children

The app does not knowingly collect any personal information from anyone, including children under 13.

1. App 的功能

HTTP Server 會把你的 Android 裝置變成區域 Wi-Fi 網路上的網頁伺服器。同一個網路內的其他裝置，可以用瀏覽器開啟畫面上顯示的網址，瀏覽、下載（在你允許時也可以上傳）你所選資料夾裡的檔案，並一起玩內建的網頁遊戲。

2. 我們蒐集的資料

開發者不會蒐集任何資料。App 內沒有任何分析、廣告、當機回報或追蹤用的 SDK，也不會把任何資料傳送給開發者或第三方伺服器。

3. 儲存在你裝置上的資料

以下資料只存在 App 於你裝置上的私有儲存空間，不會傳送給我們：

資料用途
設定（連接埠、語言、主題、網站名稱、唯讀模式、選用的網路位址）記住你的偏好設定
你透過 Android 系統資料夾選擇器所選資料夾的存取權提供該資料夾內的檔案；App 無法看到其他資料夾
選用的存取密碼避免同網路的其他人任意存取

你可以隨時清除 App 資料或解除安裝 App 來刪除以上所有資料，也可以在 Android 設定中撤銷資料夾存取權。

4. 檔案與區域網路活動

  • 檔案是在你的裝置和連線進來的瀏覽器之間，透過區域網路直接傳輸，不會經過我們的任何伺服器。
  • 伺服器執行時，App 可能會顯示最近的活動（例如哪個裝置位址瀏覽、下載或上傳了檔案），讓你知道誰在使用你的伺服器。這些資訊只會顯示在你的裝置上。
  • 玩家在網頁遊戲中輸入的名稱與遊戲狀態，只在伺服器執行期間暫存在記憶體中，並只會分享給同一個遊戲房間的其他玩家。
  • 同一網路中知道網址的任何人都可以連到伺服器。建議開啟密碼與唯讀模式，並只在你信任的網路上使用。區域網路連線使用一般 HTTP，未經加密。
