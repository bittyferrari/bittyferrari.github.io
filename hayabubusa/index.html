一路往下捲，不用一張一張按Just keep scrolling

在單圖按 C，整個資料夾的圖片就由上往下排成一長條、統一寬度。圖片尺寸先從檔頭讀出來，還沒解碼排版就是對的，捲起來不會跳。Press C in the image view and every image in the folder lines up top to bottom at the same width. Sizes are read from the file headers first, so the layout is right before anything is decoded — no jumping while you scroll.

  • 直接解碼成顯示寬度（JPEG 用 DCT 縮放解碼），省記憶體又快Decoded straight to the width it’s shown at (JPEGs in the DCT domain) — fast and light on memory
  • 先處理畫面上的，再往捲動方向預讀約兩個畫面On-screen pages first, then about two screens ahead in the direction you’re scrolling
  • 每一格畫面最多上傳一張新貼圖，捲動不卡頓At most one new texture per frame, so scrolling never stutters
  • ← → 跳到上一張／下一張的頂端，縮放比例會記住← → jump to the top of the previous / next image, and the zoom is remembered

安裝Install

Mac：打開 dmg，把 Hayabubusa 拖進「應用程式」。Windows：解壓縮，把 hayabubusa.exe 放在任何地方。Mac: open the dmg and drag Hayabubusa into Applications. Windows: unzip and put hayabubusa.exe anywhere.

選一張圖Pick an image

Mac：在 Finder 對 jpg 按 ⌘I →「打開檔案的應用程式」選 Hayabubusa →「全部更改…」。Windows：右鍵 →「開啟檔案」→「選擇其他應用程式」→ 勾「一律使用」。Mac: select a jpg in Finder, press ⌘I, choose Hayabubusa under “Open with” and click “Change All…”. Windows: right-click → “Open with” → “Choose another app” → “Always use this app”.

FAQ

常見問題Questions

真的免費嗎？Is it really free?

是的，免費而且開源，沒有廣告，也不會收集任何資料或連上網路。Yes — free and open source, with no ads, no data collection and no network access.

支援哪些格式？Which formats work?

jpg、png、webp、gif（第一格）、bmp、tiff、ico、tga，並會套用 EXIF 方向。轉檔可輸出 PNG、WEBP、JPG。jpg, png, webp, gif (first frame), bmp, tiff, ico and tga, with EXIF orientation applied. Conversions can save PNG, WEBP or JPG.

會動到我的圖嗎？Will it change my images?

只有你按旋轉、轉檔或縮放的時候。工具列的旋轉會直接覆寫檔案；單圖模式的旋轉只是預覽，要按 Ctrl／⌘ + S 才會寫入。重新編碼的 JPEG 品質是 95，EXIF 不會保留；檔案會先寫到暫存檔再取代，寫入失敗不會毀損原檔。Only when you rotate, convert or resize. Rotating from the toolbar overwrites the file; rotating in the image view is a preview until you press Ctrl / ⌘ + S. Re-encoded JPEGs are saved at quality 95 without EXIF, and files are written to a temporary file first, so a failed write never damages the original.

Mac 版和 Windows 版有什麼不同？What’s different on Mac?

看圖、縮圖、漫畫模式、旋轉轉檔都一樣。和檔案總管共用剪貼簿（剪下／複製／貼上檔案）、刪除到資源回收筒和常駐系統匣目前只有 Windows 版有。Viewing, thumbnails, comic mode, rotating and converting are the same. Sharing the clipboard with the file manager (cut / copy / paste files), deleting to the Recycle Bin and staying in the system tray are Windows-only for now.

縮圖快取和設定存在哪裡？Where are the cache and settings?

Mac：縮圖在 ~/Library/Caches/hayabubusa/thumbs，設定在 ~/Library/Application Support/hayabubusa/settings.txt。Windows：%LOCALAPPDATA%\hayabubusa\thumbs 和 %APPDATA%\hayabubusa\settings.txt。刪掉縮圖資料夾只會讓下次縮圖慢一點。Mac: thumbnails in ~/Library/Caches/hayabubusa/thumbs, settings in ~/Library/Application Support/hayabubusa/settings.txt. Windows: %LOCALAPPDATA%\hayabubusa\thumbs and %APPDATA%\hayabubusa\settings.txt. Deleting the thumbnail folder only makes the next visit a little slower.
